# Кастомні моделі: як працює конфігуратор

У розділі «Конфігуратор» покупець може замовити кастомну версію моделі авто: обрати
колір кузова (bodyColor) і колір дисків (wheelColor) через 3D-перегляд у реальному часі
(react-three-fiber). Після підтвердження вибору позиція додається в кошик під ім'ям
«<Назва моделі> (Custom)» з позначкою кастомних кольорів.

Виробництво кастомної моделі займає довше, ніж відправка моделі зі стандартного
каталогу — зазвичай 5-10 робочих днів додатково, оскільки фарбування виконується під
конкретне замовлення. Кастомні моделі не підлягають поверненню без браку (див. політику
повернень), оскільки виготовляються індивідуально під запит покупця.

Ціна кастомної моделі відповідає ціні базової моделі каталогу, з якої вона
конфігурується; додаткова плата за вибір кольору не стягується.
