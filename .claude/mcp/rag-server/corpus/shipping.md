# Доставка та Nova Poshta

TrueScale відправляє всі замовлення виключно через Нову Пошту (відділення або поштомат
за вибором покупця під час оформлення замовлення). Термін відправки — 1-3 робочих дні
з моменту підтвердження оплати. Вартість доставки покупець сплачує окремо, за тарифами
перевізника, під час отримання посилки.

Трек-номер надсилається на email, вказаний при оформленні замовлення, одразу після
створення накладної. Статус замовлення також можна перевірити в особистому кабінеті,
на сторінці «Мої замовлення».

Міжнародна доставка наразі не підтримується — лише міста й населені пункти України, де
є відділення або поштомати Нової Пошти.
