# Капсула-сюрприз

Капсула-сюрприз — це окремий розділ каталогу, де покупець платить фіксовану ціну й
отримує випадкову модель із заздалегідь визначеного пулу (capsule pool), із заданими
ймовірностями випадання для кожної рідкісності (звичайна, рідкісна, хайрарний хіт).
Список моделей у капсулі та їхні ймовірності адміністратор налаштовує в адмінпанелі,
покупцю точний список моделей до розкриття не показується — лише категорія рідкісності.

Повернення для капсули-сюрпризу не передбачено (природа продукту — випадковий дроп),
за винятком виробничого браку самої моделі, яка випала.
